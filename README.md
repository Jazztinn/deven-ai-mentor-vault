# Deven AI Mentor Vault

Public reading copy of an Obsidian research vault about Deven Seenath's videos.

Research is in progress. Source notes preserve attributed findings, quotations,
YouTube URLs, caption cue ranges, hashes, and limitations. Full-corpus synthesis
is unfinished. Public coverage is recorded in `public-export.json`.

Personal annotations, spreadsheet connections, credentials, original caption
archives, and the mentor's private records are not part of this repository.

Source-video quotations retain their original rights and attribution. The MIT
license below covers Quartz software; it does not grant rights to the videos.

Built with Quartz. Its upstream documentation follows.
